# video2ppt —— 课堂录屏自动整理成 PPT

把"老师讲 PPT"的屏幕录制视频，自动提取出**真正属于 PPT 的画面**（包括缩小窗口里放映的 PPT
和全屏放映的 PPT），去掉桌面、文件管理器、播放中的视频、"无输入信号"等非 PPT 内容，
对老师来回回顾的同一页去重，最后按出现顺序把截图贴成一份 `.pptx`。

## 该内容仅供个人参考学习使用，PPT版权属于其作者，禁止以该方法提取牟利或作其他不当提取。提取方应对行为负责。
## 该代码完全由deepseek harness生成。

只用 `ffmpeg + numpy + Pillow + python-pptx`，纯本地运行，不需要 GPU、不需要深度学习模型。
建议搭配延河课堂视频下载器，下载课程屏幕录屏后进行转换。也可转换其他类似的桌面PPT放映录屏，如腾讯会议等。

## 1. 安装依赖

```bat
:: 需要先安装 ffmpeg，并确保 ffmpeg / ffprobe 在 PATH 中
:: Windows 可直接下载 https://www.gyan.dev/ffmpeg/builds/ 解压后把 bin 加入 PATH

pip install numpy pillow python-pptx
```

## 2. 用法

```bat
python video2ppt.py "课堂录屏.mp4" -o "整理后.pptx"
```
若windows环境下，文件夹下有多个mp4文件，则可以通过命令行进行批量运行。
```bat
for %f in (*.mp4) do python video2ppt.py "%f" --workdir "_video2ppt_%~nf"
```

输出：

| 文件 | 说明 |
| --- | --- |
| `整理后.pptx` | 最终 PPT（每页一张幻灯片截图，备注里写明了来源时间） |
| `_video2ppt/slides/` | 每页的截图（默认 JPEG，加 `--png` 则为 PNG），按顺序编号 |
| `_video2ppt/slides_index.csv` | 页码、出现时间、裁剪方式、尺寸等信息 |
| `_video2ppt/dedupe_log.csv` | 去重记录（哪一页和哪一页重复、是否换成了更完整的版本） |
| `_video2ppt/candidates_sheet.png` | （`--keep-all` 时）所有候选画面拼图，方便人工检查 |
| `_video2ppt/runs_debug.csv` | （`--debug` 时）每一段静止画面的统计特征，用于调参 |

## 3. 原理（为什么这样不用大模型也能用）

1. **静止区间 = 候选幻灯片。** 以 1 帧/秒抽样，相邻抽样帧的灰度平均差很小就认为"画面没动"。
   PPT 页面静止不动，而播放视频、动画、切换幻灯片都会让画面明显变化，因此视频内容被自然排除。
   老师在同一页上长期讲解、逐步出字也属于静止区间，取区间末尾一帧即为该页最后、最完整的样子。
2. **定位页面并裁剪。** 每一帧里，幻灯片页面是"画面中最大的一块接近背景亮度的矩形"：
   - 全屏放映 4:3 幻灯片时，两侧黑边被自动排除；
   - PowerPoint 编辑窗口里，灰色画布区和左侧缩略图栏被自动排除；
   - 找不到这样的页面时退化为去掉黑边的整屏截图。
3. **过滤非 PPT 画面。** 用页面占比、背景亮度、文字/边缘密度、深色内容占比排除桌面、黑屏、
   "无信号"、文件管理器等；再用画面饱和度和宽高比（4:3 / 16:9 / 16:10 / 3:2）把彩色壁纸、
   非幻灯片形状的窗口去掉。
4. **去重。** 每页缩放到 480×360、轻微模糊后比较，并且允许上下左右 8 像素的平移对齐
   （同一页在"全屏放映"和"编辑窗口"里裁剪位置会差几个像素，先对齐再比较，避免漏判）：
   - 同一页反复出现（老师回顾）只保留第一次出现的顺序位置；
   - 若后出现的版本更完整（内容更多）或分辨率更高（例如从编辑窗口切到全屏放映），
     则用后出现的那张替换画面、但顺序位置不变。
5. **按时间顺序贴图。** 页面比例按多数截图自动选择 4:3 或 16:9，截图等比铺满。

## 4. 常用参数（不常用默认值即可）

```bat
python video2ppt.py 录屏.mp4 -o out.pptx ^
    --fps 1 ^              抽样帧率（默认 1；画面抖动大或切换很快时可调 2）
    --static-thr 2.0 ^     静止判定阈值（默认 2.0；画面噪点多/鼠标动画多时调到 3~4）
    --min-sec 3 ^          一个页面至少静止 3 秒才收录（想收录一闪而过的页面可设 2）
    --dedupe-thr 0.015 ^   去重阈值（默认 0.015；调大更宽松、可能漏掉相似页面；调小会产生重复页）
    --no-crop ^            不做页面裁剪，直接整屏截图
    --png ^                截图保存为 PNG（默认 JPEG，文件更小）
    --start 600 --duration 600   只处理一段（调试用）
```

调参建议：

- 如果结果里混进了桌面/窗口：调大 `--page-frac-min`（默认 0.12）或调小 `--dedupe-thr` 之外，
  主要看 `runs_debug.csv` 里这些区间的 `ink`（深色占比）和 `edge`（边缘密度）是否异常；
  彩色壁纸通常 `sat_hi` 很高，会在裁剪后被过滤。
- 如果漏掉了某些幻灯片：先把 `--fps 2` 和 `--min-sec 2` 打开，再看候选拼图确认。
- 如果一页被拆成好几页（鼠标动画、翻页特效导致）：调大 `--static-thr`。

## 5. 已知限制（"允许判断有一定失误"）

- 纯黑色/深色主题的幻灯片背景亮度低，可能被当作非 PPT 画面过滤掉；浅底幻灯片效果最好。
- 白底但形状不是常见幻灯片比例的窗口（例如 16:8 的文件管理器列表）可能被收进来，
  脚本用宽高比 + 饱和度尽量过滤，但不能保证 100%。
- 同一模板、只差几个字的页面在像素上非常接近，
  去重阈值过大会误合并，默认阈值取 0.015 以偏保守（宁可重复，不误删）。
- 视频里播放的录屏/动画一般会因画面持续变化被排除；但若某段视频长时间停在静止画面上，
  且画面像一张"幻灯片"，仍可能被收录。


## 6. 在其他视频上使用

- 脚本对分辨率、比例、PPT 主题、老师窗口大小都不做假设（内部按比例缩放分析），
同一套参数可以直接用于其他"课堂录屏 + PPT"视频；只有极端的录屏方式
（例如 PPT 只占屏幕很小一角且背景是壁纸照片）才需要配合 `--no-crop` 或调参。
- 过程文件都在 `_video2ppt/`：`slides/` 是截图，`slides_sheet.png` 是全部页面的缩略拼图，
  `candidates_sheet.png` 是候选画面的拼图，`slides_index.csv` 记录每页来源时间。
